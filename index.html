🎮 CONTROLS & FLIGHT MANUAL

⌨️ Keyboard Flight Controls

  • W / S : Throttle Up / Down
  • A / D : Yaw Left / Right
  • ↑ / ↓ : Pitch Forward / Backward
  • ← / → : Roll Left / Right
  • Space : Air Brake / Emergency Hover
  • C : Cycle Camera (FPV, Chase, Orbit, Top)
  • M : Cycle Flight Mode (Stabilized / Acro / Hover)
  • E : Toggle Track Builder Mode
  • R : Reset Drone Position

🛠️ Track Builder Sandbox Controls

  • Left Click Item : Select prop from palette
  • Click 3D Ground : Place selected prop
  • Click Object : Select prop in 3D scene
  • R : Rotate selected prop 45°
  • ↑ / ↓ or Buttons : Adjust prop height
  • Delete : Delete selected prop
  • Drag RMB : Orbit Editor Camera
